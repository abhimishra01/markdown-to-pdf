# Code review, regression lens: Markdown to PDF

Verdict: core conversion, sanitizer, @page CSS and print path are correct (25/25 tests pass; real Chrome PDFs checked); 1 must-fix (loose task lists render a bullet plus a checkbox), 6 should-fix.

Checked by hand and in Chrome: Letter and A4 `@page` size (612x792 and 595x842 pt), margins, "n / N" page numbers (Letter and A4 wide: correct on every page; off: none), real text in the PDF, footnote links become working internal PDF links, external link kept. Page estimate vs real PDF: A4 narrow 22 vs 22, A4 wide 30 vs 30, Letter normal 28 vs 30 (undercounts when headings and tables force breaks; "about" covers it). Template rules hold: canonical on all 6 pages, pages.dev noindex in `_headers`, legal pages linked in footer, 404 is noindex and left out of the sitemap, GA and AdSense output nothing when empty, ads.txt is a comment only. Known template leftovers (README, new-tool.sh, tracked screenshots, duplicate legal links, build-date "Last updated", British spelling): not reviewed.
