# Code review, maintainer lens (Kim)

Verdict: solid, small and well tested at the library level (25 tests pass, sanitizer holds against the vectors I tried), but one real correctness bug for the main audience (README table-of-contents links are dead) and the UI script has no error handling or tests for huge or odd input. 1 must-fix, 8 should-fix.

Template leftovers (template README, scripts/new-tool.sh, tracked screenshots, duplicate legal links, build-date "Last updated", British spelling) are on the fixer's list and not repeated here.

How I checked: read all of src/, tests, config. Ran `npm test` (25 pass). Ran 17 hostile inputs through `makeSanitizer` in jsdom (base, link, meta, svg, math, data: and java&#9;script: links, forms, srcset, handlers): all neutralised. Timed parse + sanitize on large input. Did not start a server.
